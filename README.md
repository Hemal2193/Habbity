# Habity

<img width="1188" height="648" alt="Habity readme" src="https://://github.com/user-attachments/assets/ccc21cbf-0e78-4d1b-9458-ed03f4a8fcde" />

Habity is a clean and modern habit tracking app built with Flutter.  
It helps users build consistency, track daily progress, and maintain streaks through a beautiful dark-themed experience with simple but useful analytics.

Designed with a smooth Material 3 UI and local-first storage, Habity focuses on fast interaction, distraction-free habit management, and a visually polished experience.

---

## ✨ Features

### 📝 Habit Management
- Create and manage daily habits easily
- Add optional habit descriptions
- Edit existing habits without losing progress history
- Delete habits with confirmation protection
- Beautiful habit cards with custom icons and colors

### ✅ Daily Tracking
- Mark habits as completed for the current day
- Visual completion states with animations and glow effects
- Daily progress indicator showing completed habits ratio
- Automatic streak tracking

### 📊 Statistics & Insights
- Current streak tracking
- Longest streak calculation
- Completion rate analytics
- Total completions overview
- Dedicated statistics screen for all habits

### 🎨 Modern UI
- Dark Material 3 design
- Purple-blue gradient interface
- Smooth animations and transitions
- Rounded glass-style cards
- Responsive and clean layout

### 💾 Local Persistence
- Offline-first experience
- Automatic saving using `SharedPreferences`
- JSON-based local data storage
- Habit data persists across app restarts

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed
- Android Studio / VS Code
- Android Emulator or Physical Device

### Run Locally

```bash
git clone https://github.com/your-username/habity.git
cd habity
flutter pub get
flutter run
```
